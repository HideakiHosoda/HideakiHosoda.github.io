ここでは、授業・自主練習用の小さなコード課題をまとめます。すべてHTML+CSS（必要に応じて少量のJS）。

Exercise 1: カラーブロックのグリッド

CSS Gridで均等割りのタイルを作るミニ課題。

<style>
.grid { display:grid; grid-template-columns:repeat(6,1fr); gap:8px; }
.tile { aspect-ratio:1 / 1; background:#00000026; border-radius:10px; }
.grid .tile:nth-child(6n+1){ background:#ffeb3b; }
.grid .tile:nth-child(6n+2){ background:#7cc4ff; }
.grid .tile:nth-child(6n+3){ background:#ff8a50; }
.grid .tile:nth-child(6n+4){ background:#fff; }
.grid .tile:nth-child(6n+5){ background:#00000066; }
</style>

<div class="grid">
  <div class="tile"></div>  <div class="tile"></div>  <div class="tile"></div>
  <div class="tile"></div>  <div class="tile"></div>  <div class="tile"></div>
  <!-- 好きなだけ増やす -->
</div>

Exercise 2: レスポンシブ・ヒーロー

clamp() を使って見出しが画面幅で滑らかに伸縮する見本。

.hero-demo{
  min-height:40vh; display:grid; place-items:center; text-align:center;
}
.hero-demo h1{ font-size:clamp(2rem,8vw,6rem); color:#ffeb3b; }
.hero-demo p{ font-size:clamp(1rem,3vw,1.6rem); color:#7cc4ff; }
